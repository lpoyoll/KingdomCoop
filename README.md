# KingdomCoop

Kingdom Come: Deliverance II companion co-op project.

## Goal

Henry remains the campaign protagonist and host authority. Other players join his campaign as persistent physical companions with their own identity, inventory, equipment, money, health, progression and co-op state.

The project is being built from `DeepFriedDepp/kcd2-multiplayer_Reworked` and retains the upstream GPL-3.0 licensing obligations. The initial upstream baseline for this repository is `0.17.1` at commit `8e2cede52bc946f54992e1d3a62c736adfcebbcc`.

## Companion Co-op scope

The first integrated build is gated on all of the following systems existing together: persistent companion inventory/shared loot/trading, host-following world transitions, either-player down/revive with all-down party wipe and Henry reload, host-canonical NPC combat, dialogue spectator mode, quest-safe guest rules, per-player crime, persistent companion identity, companion progression, and a simplified Host Campaign / Join Companion launcher.
